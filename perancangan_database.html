🗄️ Perancangan Database & Kamus Data

Desain Tabel dan Pengkodean untuk Entitas Utama Aplikasi E-Learning

Tabel: users (Data Pengguna)

Nama Field Tipe Data Key Keterangan
idBIGINT(20)Primary KeyID unik pengguna (Auto Increment)
nameVARCHAR(255)-Nama lengkap pengguna
emailVARCHAR(255)UniqueAlamat email untuk login
passwordVARCHAR(255)-Password pengguna (Ter-enkripsi)
roleENUM-Peran pengguna: 'admin', 'teacher', 'student'
created_atTIMESTAMP-Waktu data dibuat

Tabel: students (Data Siswa)

Nama Field Tipe Data Key Keterangan
idBIGINT(20)Primary KeyID unik siswa (Auto Increment)
user_idBIGINT(20)Foreign KeyRelasi ke tabel users
classroom_idBIGINT(20)Foreign KeyRelasi ke tabel classrooms (Kelas Siswa)
nisnVARCHAR(20)UniqueNomor Induk Siswa Nasional
nisVARCHAR(20)UniqueNomor Induk Siswa (Lokal)
phoneVARCHAR(20)-Nomor telepon / WhatsApp siswa
statusVARCHAR(50)-Status akademik ('aktif', 'lulus', dll)

Tabel: payment_categories (Kategori Pembayaran)

Nama Field Tipe Data Key Keterangan
idBIGINT(20)Primary KeyID Kategori (Auto Increment)
academic_year_idBIGINT(20)Foreign KeyTahun ajaran pemberlakuan kategori
nameVARCHAR(255)-Nama Kategori (misal: "SPP Bulan Juli")
codeVARCHAR(50)-Kode pembayaran sistem
default_amountDECIMAL(12,2)-Nominal default tagihan

Tabel: bills (Tagihan Siswa)

Nama Field Tipe Data Key Keterangan
idBIGINT(20)Primary KeyID Tagihan (Auto Increment)
student_idBIGINT(20)Foreign KeyTarget tagihan perorangan (Relasi ke students)
payment_category_idBIGINT(20)Foreign KeyRelasi ke tabel payment_categories
amountDECIMAL(12,2)-Jumlah uang yang harus dibayar
total_paidDECIMAL(12,2)-Total uang yang sudah dibayar (Akumulasi)
statusENUM-Status ('unpaid', 'partial', 'paid')
due_dateDATE-Tenggat waktu pembayaran

Tabel: transactions (Riwayat Transaksi)

Nama Field Tipe Data Key Keterangan
idBIGINT(20)Primary KeyID Transaksi (Auto Increment)
bill_idBIGINT(20)Foreign KeyTagihan yang dibayarkan
order_idVARCHAR(100)UniqueKode ID Transaksi dari Midtrans (Pengkodean referensi)
amountDECIMAL(12,2)-Nominal transaksi yang diproses
payment_typeVARCHAR(50)-Jenis pembayaran (bank_transfer, qris, dll)
statusVARCHAR(50)-Status transaksi ('pending', 'success', 'failed', 'expire')
