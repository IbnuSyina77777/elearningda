sequenceDiagram autonumber actor Browser as Pengguna (Browser) participant Route as Routes (web.php) participant Controller as Controller participant Model as Model (Eloquent) participant Database as Database (MySQL) participant View as View (Blade Template) Browser->>Route: Kirim HTTP Request (contoh: GET /bills) Route->>Controller: Teruskan ke Controller (Route to Action) activate Controller Controller->>Model: Request Data (contoh: Bill::with('student')->get()) activate Model Model->>Database: Eksekusi Query SQL activate Database Database-->>Model: Mengembalikan Data (Result Set) deactivate Database Model-->>Controller: Mengembalikan Data berupa Object/Collection deactivate Model Controller->>View: Parsing Data ke View (compact('bills')) activate View View-->>Controller: Mengembalikan kode HTML yang sudah ter-render deactivate View Controller-->>Browser: Kirim HTTP Response (Tampilkan Halaman di Browser) deactivate Controller
